RemoteControlRegistry
=====================

**Inherits:** :ref:`Object<class_Object>`

Registry of remote control commands exposed over HTTP and to scripts.

.. rst-class:: classref-introduction-group

Description
-----------

Engine singleton that stores named commands as callables. Built-in commands are registered when :ref:`RemoteControlServer<class_RemoteControlServer>` starts. Projects can add custom commands with :ref:`register_command()<class_RemoteControlRegistry_method_register_command>`.

Commands are invoked via ``POST /v1/exec`` with body ``{ "command": "name", "args": {} }`` or through :ref:`execute()<class_RemoteControlRegistry_method_execute>`.
