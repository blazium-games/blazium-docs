HTTPResponse
============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Builder for constructing HTTP responses in route handlers.

.. rst-class:: classref-introduction-group

Description
-----------

HTTPResponse provides a fluent API for building HTTP responses. It is automatically created by :ref:`HTTPServer<class_HTTPServer>` and passed to route handler callbacks. You can set the status code, headers, and body content, or serve files and start Server-Sent Events streams.


.. tabs::

 .. code-tab:: gdscript

    HTTPServer.register_route("GET", "/api/data", func(req, res: HTTPResponse):
        # Set JSON response
        res.set_json({"message": "Hello"})
    
        # Or set custom status and headers
        res.set_status(201)
        res.add_header("X-Custom", "Value")
        res.set_body("Custom response")
    
        # Or serve a file
        res.set_file("user://data.json")
    
        # Or start SSE stream
        res.start_sse()
    )

.. _class_HTTPResponse_method_start_sse:

.. rst-class:: classref-method

|void| **start_sse**\ (\ ) :ref:`🔗<class_HTTPResponse_method_start_sse>`

Configures the response as a Server-Sent Events stream. This sets the appropriate headers (Content-Type: text/event-stream) and keeps the connection open for streaming events. After calling this, use :ref:`HTTPServer.send_sse_event()<class_HTTPServer_method_send_sse_event>` to send events to the client.

::

    func _on_sse(ctx: HTTPRequestContext, res: HTTPResponse):
        res.start_sse()
        # Target the new stream externally via HTTPServer.send_sse_event()
