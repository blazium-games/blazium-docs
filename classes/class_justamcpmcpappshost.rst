JustAMCPMCPAppsHost
===================

**Inherits:** :ref:`Object<class_Object>`

Host for MCP Apps UI iframes served from the local JustAMCP HTTP server.

.. rst-class:: classref-introduction-group

Description
-----------

Detects ``_meta.ui.resourceUri`` on remote tools, enforces deny-by-default CSP and permissions, and proxies App Bridge ``tools/call`` messages through :ref:`JustAMCPMCPClientBridge<class_JustAMCPMCPClientBridge>` after user consent. The host page is served at ``/mcp-apps/host``.
