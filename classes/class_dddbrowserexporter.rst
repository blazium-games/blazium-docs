DDDBrowserExporter
==================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Exports a scene tree to a DDDBrowser page (OBJ/MTL meshes, scene JSON, discovery HTML).

.. rst-class:: classref-introduction-group

Description
-----------

Walks a normal Blazium scene (and optional :ref:`DDDBrowserLevel<class_DDDBrowserLevel>` metadata) into DDDBrowser ``scene.json`` plus assets.

\ **Dedicated nodes** (:ref:`DDDBrowserSpawn<class_DDDBrowserSpawn>`, :ref:`DDDBrowserModel<class_DDDBrowserModel>`, portals, volumes, textbox/picturebox/audio/font/script) win over heuristics when both apply.

\ **Normal-scene heuristics**: first :ref:`Camera3D<class_Camera3D>` or a :ref:`Marker3D<class_Marker3D>` named ``Spawn`` → ``spawn``; :ref:`MeshInstance3D<class_MeshInstance3D>` / :ref:`StaticBody3D<class_StaticBody3D>` → OBJ+MTL model (+ albedo textures and :ref:`CollisionShape3D<class_CollisionShape3D>` colliders); :ref:`Light3D<class_Light3D>`; :ref:`AudioStreamPlayer3D<class_AudioStreamPlayer3D>` (wav/ogg); :ref:`Label3D<class_Label3D>` → textbox; :ref:`Sprite3D<class_Sprite3D>` / :ref:`DDDBrowserPicturebox<class_DDDBrowserPicturebox>` → picturebox; :ref:`WorldEnvironment<class_WorldEnvironment>` sky → ``skybox.uri`` when level skybox is unset.

\ **LuauScript**: attached ``.luau`` / LuauScript resources on exported instances are copied into ``scripts/`` and wired as ``instances[].script`` (source passthrough). Prefer attaching a Blazium Luau ``gdclass`` extending :ref:`Node3D<class_Node3D>`; DDDBrowser runs ``_ready`` / ``_process`` via its gdclass compatibility layer.

Skipped with warning: rigid/character physics semantics, :ref:`AnimationPlayer<class_AnimationPlayer>`, CSG (unless already a baked mesh), unsupported collision shapes / streams.

Call :ref:`get_last_warning()<class_DDDBrowserExporter_method_get_last_warning>` after export for skip/heuristic messages.
