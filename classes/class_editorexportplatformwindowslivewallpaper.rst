EditorExportPlatformWindowsLiveWallpaper
========================================

**Inherits:** :ref:`EditorExportPlatformWindows<class_EditorExportPlatformWindows>` **<** :ref:`EditorExportPlatformPC<class_EditorExportPlatformPC>` **<** :ref:`EditorExportPlatform<class_EditorExportPlatform>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Exports a Windows live wallpaper ``.exe`` using livewallpaper-flavored templates.

.. rst-class:: classref-introduction-group

Description
-----------

Looks up ``windows_{debug|release}_{arch}.livewallpaper.exe`` only. There is no fallback to the Desktop ``windows_*.exe`` template. Packed project settings force ``blazium/livewallpaper/enabled=true``. Build those templates with ``livewallpaper_template=yes``.
