InterDVDIfoWriter
=================

**Inherits:** :ref:`Object<class_Object>`

Writes a VIDEO_TS / AUDIO_TS DVD-Video volume from an :ref:`InterDVDProject<class_InterDVDProject>`.

.. rst-class:: classref-introduction-group

Description
-----------

Creates unencrypted IFO/BUP/VOB files for burning. There is no in-engine disc player. Dummy title VOBs are for tests only when no MPEG-2 cell is available.

.. _class_InterDVDIfoWriter_method_write_video_ts:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **write_video_ts**\ (\ root\: :ref:`String<class_String>`, project\: :ref:`InterDVDProject<class_InterDVDProject>`, allow_dummy_vob\: :ref:`bool<class_bool>` = false, ffmpeg\: :ref:`String<class_String>` = "", auto_find_ffmpeg\: :ref:`bool<class_bool>` = true, progress\: :ref:`InterDVDExportProgress<class_InterDVDExportProgress>` = null\ ) |static| :ref:`🔗<class_InterDVDIfoWriter_method_write_video_ts>`

Writes ``VIDEO_TS``, ``AUDIO_TS``, extras, and ``disc.interdvd.json`` under ``root``. Returns :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>` on success. Every :ref:`InterDVDCell<class_InterDVDCell>` on a title is muxed into ``VTS_01_1.VOB`` (append + reindex). Cell N is chapter N (PGN N / PTT N). A cell can use :ref:`InterDVDCell.encoded_path<class_InterDVDCell_property_encoded_path>`, bake :ref:`InterDVDCell.packed_scene<class_InterDVDCell_property_packed_scene>` for :ref:`InterDVDCell.duration_sec<class_InterDVDCell_property_duration_sec>`, copy an already-encoded MPEG-2/VOB :ref:`InterDVDCell.source_path<class_InterDVDCell_property_source_path>`, or transcode other sources through ``blazium-toolchain interdvd ffmpeg``. ``ffmpeg`` and ``auto_find_ffmpeg`` are unused; encoding always goes through the toolchain. When ``allow_dummy_vob`` is ``true``, a dummy title VOB is written if no cell or toolchain is available. ``progress`` receives step/total/label updates and prints elapsed plus ETA.
