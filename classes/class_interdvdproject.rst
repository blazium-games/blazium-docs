InterDVDProject
===============

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Authoring graph for a VIDEO_TS / AUDIO_TS disc.

.. rst-class:: classref-introduction-group

Description
-----------

Compiled disc graph consumed by the IFO writer. Prefer an :ref:`InterDVDDisc<class_InterDVDDisc>` scene tree; export calls :ref:`InterDVDDisc.build_project()<class_InterDVDDisc_method_build_project>`. A saved ``.tres`` still works when ``blazium/inter_dvd/project`` is set. Encode fields on this resource are used during bake/mux.
