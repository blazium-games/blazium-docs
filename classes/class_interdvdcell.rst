InterDVDCell
============

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

One DVD-Video cell: a Godot scene to bake, pre-encoded MPEG-2/VOB, or a source file to transcode.

.. rst-class:: classref-introduction-group

Description
-----------

One muxed VOB cell. Export resolution order: :ref:`encoded_path<class_InterDVDCell_property_encoded_path>` if it exists; otherwise bake :ref:`packed_scene<class_InterDVDCell_property_packed_scene>` for :ref:`duration_sec<class_InterDVDCell_property_duration_sec>`; otherwise copy or transcode :ref:`source_path<class_InterDVDCell_property_source_path>`. A title PGC muxes every cell (cell N is chapter N / program N). A scene bake records 720×480 video plus a 48 kHz stereo AC3 track. Missing encoder plus no encoded cell is an export error unless dummy VOB is allowed. No CSS is applied.
