SemanticAsyncSearchWorker
=========================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Background worker that runs semantic asset searches off the main thread.

.. rst-class:: classref-introduction-group

Description
-----------

Queues asynchronous semantic search jobs through the active :ref:`SemanticSearchBackend<class_SemanticSearchBackend>`. Poll jobs with :ref:`poll_search()<class_SemanticAsyncSearchWorker_method_poll_search>` until they finish or are cancelled.
