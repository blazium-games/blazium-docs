ResourceImporterGIF
===================

**Inherits:** :ref:`ResourceImporter<class_ResourceImporter>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Imports a ``.gif`` file as an animated :ref:`GIFTexture<class_GIFTexture>`.

.. rst-class:: classref-introduction-group

Description
-----------

Default importer for ``.gif`` files. Decodes the animation into a :ref:`GIFTexture<class_GIFTexture>`, which plays back in any node accepting a :ref:`Texture2D<class_Texture2D>`. To import the same file as a :ref:`SpriteFrames<class_SpriteFrames>` for :ref:`AnimatedSprite2D<class_AnimatedSprite2D>` instead, select **SpriteFrames** in the Import dock's Import As dropdown (:ref:`ResourceImporterGIFFrames<class_ResourceImporterGIFFrames>`).
