JustAMCPTaskManager
===================

**Inherits:** :ref:`Object<class_Object>`

Tracks long-running MCP tasks and their results.

.. rst-class:: classref-introduction-group

Description
-----------

**JustAMCPTaskManager** stores task metadata for MCP operations that complete asynchronously. It generates task UUIDs, reports status transitions (including ``notifications/tasks/status`` via :ref:`JustAMCPServer<class_JustAMCPServer>`), blocks ``tasks/result`` until a terminal state, and records cancellation or failure.

Configure defaults with :ref:`ProjectSettings.blazium/justamcp/task_default_ttl_ms<class_ProjectSettings_property_blazium/justamcp/task_default_ttl_ms>`, :ref:`ProjectSettings.blazium/justamcp/task_poll_interval_ms<class_ProjectSettings_property_blazium/justamcp/task_poll_interval_ms>`, and :ref:`ProjectSettings.blazium/justamcp/task_max_concurrent<class_ProjectSettings_property_blazium/justamcp/task_max_concurrent>`.

See the MCP `Tasks <https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/tasks>`__ utility.
