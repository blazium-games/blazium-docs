JustAMCPResourceUI
==================

**Inherits:** :ref:`JustAMCPResource<class_JustAMCPResource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Serves sandboxed MCP App HTML from ``ui://`` URIs.

.. rst-class:: classref-introduction-group

Description
-----------

Serves MCP App HTML from ``ui://.blazium/apps/*.html``. ``ui://.blazium/apps/host.html`` is the embedded module host page; other ``*.html`` names map to ``res://.blazium/apps/``. Paths containing ``..`` or outside that prefix are rejected.
