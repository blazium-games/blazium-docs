LexicalTagBackend
=================

**Inherits:** :ref:`SemanticSearchBackend<class_SemanticSearchBackend>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Semantic search backend backed by the lexical asset tag index.

.. rst-class:: classref-introduction-group

Description
-----------

Delegates search, similarity, rebuild, and stats calls to :ref:`SemanticAssetIndex<class_SemanticAssetIndex>`. This is the default lightweight backend when embedding providers are not required.
