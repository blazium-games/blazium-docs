GIFRecorder
===========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Records a viewport, window, or screen to an animated GIF.

.. rst-class:: classref-introduction-group

Description
-----------

Works in the editor and in exported templates. Capture a :ref:`Viewport<class_Viewport>` with :ref:`start_viewport()<class_GIFRecorder_method_start_viewport>`, the engine window with :ref:`start_window()<class_GIFRecorder_method_start_window>`, or a display with :ref:`start_screen()<class_GIFRecorder_method_start_screen>`. Tests and manual control can push images with :ref:`add_frame()<class_GIFRecorder_method_add_frame>`. Call :ref:`stop()<class_GIFRecorder_method_stop>` then :ref:`save()<class_GIFRecorder_method_save>`, or use :ref:`record_viewport()<class_GIFRecorder_method_record_viewport>` for a timed clip.
