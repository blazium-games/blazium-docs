DDDBrowserLevel
===============

**Inherits:** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Root node for authoring a DDDBrowser level in the editor.

.. rst-class:: classref-introduction-group

Description
-----------

Holds scene metadata used by :ref:`DDDBrowserExporter<class_DDDBrowserExporter>`: name, rating, skybox (uri or six faces), world, gameType, movement bounds, autosave notification, and manifest URL.

\ :ref:`gamemode_file<class_DDDBrowserLevel_property_gamemode_file>` should be a ``.luau`` path; export copies it into ``scripts/`` and emits ``gamemode.file`` as the **filename** (for example ``gamemode_template.luau``), which is what DDDBrowser resolves—not an asset id.
