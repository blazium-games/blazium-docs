InterDVDEditorPlugin
====================

**Inherits:** :ref:`EditorPlugin<class_EditorPlugin>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Registers the Interactive DVD export platform.

.. rst-class:: classref-introduction-group

Description
-----------

Adds :ref:`EditorExportPlatformWindowsInterDVD<class_EditorExportPlatformWindowsInterDVD>` and Project → Tools → Create Interactive DVD Scene. Disc, title, and menu inspectors add :ref:`InterDVDTitle<class_InterDVDTitle>`, :ref:`InterDVDChapter<class_InterDVDChapter>`, :ref:`InterDVDMenuPage<class_InterDVDMenuPage>`, and :ref:`InterDVDHotspot<class_InterDVDHotspot>` nodes. There is no play-in-editor disc player.
