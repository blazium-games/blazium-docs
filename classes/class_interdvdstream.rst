InterDVDStream
==============

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Extra audio or subtitle stream muxed into an :ref:`InterDVDCell<class_InterDVDCell>`.

.. rst-class:: classref-introduction-group

Description
-----------

:ref:`InterDVDCell.audio_path<class_InterDVDCell_property_audio_path>` is stream 0. Additional AC3 audio tracks use :ref:`KIND_AUDIO<class_InterDVDStream_constant_KIND_AUDIO>` (private stream ``0x81+``). Caption files (``.srt``, ``.sup``) use :ref:`KIND_SUBTITLE<class_InterDVDStream_constant_KIND_SUBTITLE>` and are muxed as ``dvdsub`` (private stream ``0x20+``). IFO stream tables are written only when that PES exists in the muxed VOB.
