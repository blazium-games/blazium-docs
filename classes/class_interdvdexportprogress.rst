InterDVDExportProgress
======================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Step, elapsed, and ETA reporting for Interactive DVD export.

.. rst-class:: classref-introduction-group

Description
-----------

:ref:`InterDVDIfoWriter.write_video_ts()<class_InterDVDIfoWriter_method_write_video_ts>` and editor export call :ref:`report()<class_InterDVDExportProgress_method_report>` for each bake/mux/IFO/finalize step. Headless prints ``export_dvd: [n/N] label  elapsed mm:ss  eta mm:ss``. Optional :ref:`notify<class_InterDVDExportProgress_property_notify>` receives ``(step, total, label, line)``.
