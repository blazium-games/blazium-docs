InterDVDMenuPage
================

**Inherits:** :ref:`Control<class_Control>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

A VMGM or VTSM menu page that compiles to :ref:`InterDVDMenu<class_InterDVDMenu>`.

.. rst-class:: classref-introduction-group

Description
-----------

720×480 Control. :ref:`InterDVDMenu.MENU_TITLE<class_InterDVDMenu_constant_MENU_TITLE>` menus mux into ``VIDEO_TS.VOB``. Other types mux into ``VTS_01_0.VOB``. Default :ref:`still_time<class_InterDVDMenuPage_property_still_time>` is 0 so VLC does not freeze on the title menu. Child :ref:`InterDVDHotspot<class_InterDVDHotspot>` nodes are the menu buttons.
