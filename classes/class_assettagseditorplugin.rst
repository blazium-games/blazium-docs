AssetTagsEditorPlugin
=====================

**Inherits:** :ref:`EditorPlugin<class_EditorPlugin>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Editor plugin for managing asset tags.

.. rst-class:: classref-introduction-group

Description
-----------

Adds an **Asset Tags** tab to the Project Settings dialog for managing the project tag dictionary: browsing the tag tree, editing comments, renaming or removing tags, and cleaning up unused tags. Per-asset tag assignment is available from the FileSystem dock context menu via **Edit Asset Tags...**. Coordinates with :ref:`AssetTagManager<class_AssetTagManager>`, :ref:`AssetTagRegistry<class_AssetTagRegistry>`, and :ref:`AssetTagCoordinator<class_AssetTagCoordinator>` for undo-aware mutations.
