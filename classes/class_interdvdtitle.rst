InterDVDTitle
=============

**Inherits:** :ref:`Control<class_Control>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

One VTS title PGC in an :ref:`InterDVDDisc<class_InterDVDDisc>` tree. Layout canvas is 720×480.

.. rst-class:: classref-introduction-group

Description
-----------

720×480 Control. Child :ref:`InterDVDChapter<class_InterDVDChapter>` nodes become chapters. Child :ref:`InterDVDHotspot<class_InterDVDHotspot>` nodes become title-domain buttons. Set :ref:`menu_title<class_InterDVDTitle_property_menu_title>` for a VLC-safe menu return target (Jump Title, not CallSS).
