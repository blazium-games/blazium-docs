InterDVDDisc
============

**Inherits:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Scene-tree root for an Interactive DVD. Compiles to :ref:`InterDVDProject<class_InterDVDProject>` at export.

.. rst-class:: classref-introduction-group

Description
-----------

Author titles, menus, and encode settings on this node instead of ProjectSettings. Child :ref:`InterDVDTitle<class_InterDVDTitle>` and :ref:`InterDVDTitleSet<class_InterDVDTitleSet>` nodes become VTS titles. Child :ref:`InterDVDMenuPage<class_InterDVDMenuPage>` nodes become VMGM/VTSM menus. :ref:`build_project()<class_InterDVDDisc_method_build_project>` is the export IR. Project → Tools → Create Interactive DVD Scene inserts a VLC-safe skeleton (title menu, main title, menu title).
