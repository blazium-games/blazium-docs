InterDVDSceneBaker
==================

**Inherits:** :ref:`Object<class_Object>`

Records an :ref:`InterDVDCell<class_InterDVDCell>` packed scene to NTSC DVD MPEG-2 plus audio.

.. rst-class:: classref-introduction-group

Description
-----------

Instantiates :ref:`InterDVDCell.packed_scene<class_InterDVDCell_property_packed_scene>` in a 720×480 viewport, captures :ref:`InterDVDCell.duration_sec<class_InterDVDCell_property_duration_sec>` at 30 fps, and encodes with ffmpeg ``-target ntsc-dvd``. GPU capture uses the scene (or :ref:`InterDVDCell.bake_camera_path<class_InterDVDCell_property_bake_camera_path>`) camera; dummy/headless CPU-rasters common Node2D and Control types. A packed :ref:`Node3D<class_Node3D>` on the dummy renderer returns :ref:`@GlobalScope.ERR_UNAVAILABLE<class_@GlobalScope_constant_ERR_UNAVAILABLE>`. :ref:`AnimationPlayer<class_AnimationPlayer>` / :ref:`AnimatedSprite2D<class_AnimatedSprite2D>` scenes bake looping motion frames. A root ``inter_dvd_bake_time(seconds)`` method is called each captured frame. :ref:`InterDVDCell.bake_hold_sec<class_InterDVDCell_property_bake_hold_sec>` or ``inter_dvd_bake_hold_sec()`` holds each unique frame. Cache path, AC3, GOP, PiP lead, and warmup come from ProjectSettings / :ref:`InterDVDProject<class_InterDVDProject>` / :ref:`InterDVDCell<class_InterDVDCell>`. Fails if the probed MPEG is shorter than the requested duration. Editor-only.
