DDDBrowserPreviewServer
=======================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Serves an exported DDDBrowser page via :ref:`HTTPServer<class_HTTPServer>` for local testing.

.. rst-class:: classref-introduction-group

Description
-----------

Registers GET routes and uses :ref:`HTTPResponse.set_file()<class_HTTPResponse_method_set_file>`. Enable Allow HTTP in DDDBrowser when loading ``http://127.0.0.1`` URLs.
