AssetTagsContextMenuPlugin
==========================

**Inherits:** :ref:`EditorContextMenuPlugin<class_EditorContextMenuPlugin>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

FileSystem dock context menu entry for editing asset tags.

.. rst-class:: classref-introduction-group

Description
-----------

Adds **Edit Asset Tags...** to the FileSystem dock right-click menu for taggable assets. Opens the asset tags editor dialog so selected files can have tags assigned or removed. Registered by :ref:`AssetTagsEditorPlugin<class_AssetTagsEditorPlugin>`.
