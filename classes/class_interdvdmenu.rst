InterDVDMenu
============

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Still or motion DVD menu with up to 36 buttons.

.. rst-class:: classref-introduction-group

Description
-----------

Used when authoring VMG/VTSM menus. Playback happens on a burnt disc, not in the editor. Set :ref:`Resource.resource_name<class_Resource_property_resource_name>` so button destination dropdowns can label this menu.
