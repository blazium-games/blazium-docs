JustAMCPToolExecutor
====================

**Inherits:** :ref:`Object<class_Object>`

Routes MCP tool calls to the matching JustAMCP tool implementation.

.. rst-class:: classref-introduction-group

Description
-----------

**JustAMCPToolExecutor** builds the available tool schema list and dispatches validated tool calls to specialized tool groups such as :ref:`JustAMCPSceneTools<class_JustAMCPSceneTools>`, :ref:`JustAMCPResourceTools<class_JustAMCPResourceTools>`, :ref:`JustAMCPScriptTools<class_JustAMCPScriptTools>`, and :ref:`JustAMCPDocumentationTools<class_JustAMCPDocumentationTools>`. Use it when code needs the same tool surface exposed to MCP clients.

Long-running tools expose ``execution.taskSupport: optional`` in schemas (autowork, export, batch, editor play/reload) for MCP task-augmented ``tools/call``.

::

    var schemas = JustAMCPToolExecutor.get_tool_schemas()
    var executor = JustAMCPToolExecutor.new()
    var response = executor.execute_tool("scene_tree", {})
    print(response)
