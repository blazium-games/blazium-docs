ResourceImporterGIFFrames
=========================

**Inherits:** :ref:`ResourceImporter<class_ResourceImporter>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Imports a ``.gif`` file as a :ref:`SpriteFrames<class_SpriteFrames>` resource.

.. rst-class:: classref-introduction-group

Description
-----------

Alternative importer for ``.gif`` files, selectable via the Import dock's Import As dropdown. Decodes the animation into a :ref:`SpriteFrames<class_SpriteFrames>` with the animation named ``default``, suitable for :ref:`AnimatedSprite2D<class_AnimatedSprite2D>` and :ref:`AnimationPlayer<class_AnimationPlayer>` workflows. For standard texture playback instead, use the default GIF importer (:ref:`ResourceImporterGIF<class_ResourceImporterGIF>`).
