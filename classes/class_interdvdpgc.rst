InterDVDPGC
===========

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Program Chain: cells plus pre/post instruction arrays.

.. rst-class:: classref-introduction-group

Description
-----------

PGC pre/post and cell-post sites are written into the IFO. First Play (FPC) is a PGC on :ref:`InterDVDProject<class_InterDVDProject>`. Set :ref:`Resource.resource_name<class_Resource_property_resource_name>` so button destination dropdowns can label this title. The inspector **DVD Authoring** buttons append a video cell or a Jump Title highlight.
