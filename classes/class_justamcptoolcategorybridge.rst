JustAMCPToolCategoryBridge
==========================

**Inherits:** :ref:`Object<class_Object>`

Adapts a JustAMCP tool category into a registered toolset provider.

.. rst-class:: classref-introduction-group

Description
-----------

Bridges a single tool category to :ref:`JustAMCPToolsetRegistry<class_JustAMCPToolsetRegistry>` by forwarding schema collection and execution to :ref:`JustAMCPToolExecutor<class_JustAMCPToolExecutor>`. Used when modular toolsets expose category-scoped tools through discovery meta-tools.
