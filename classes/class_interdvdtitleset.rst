InterDVDTitleSet
================

**Inherits:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

One Video Title Set under an :ref:`InterDVDDisc<class_InterDVDDisc>`.

.. rst-class:: classref-introduction-group

Description
-----------

Groups :ref:`InterDVDTitle<class_InterDVDTitle>` children and non-title :ref:`InterDVDMenuPage<class_InterDVDMenuPage>` children into ``VTS_NN_*``. VMGM title menus stay direct children of :ref:`InterDVDDisc<class_InterDVDDisc>`. Titles not under a set compile as VTS 1.
