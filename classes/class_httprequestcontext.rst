HTTPRequestContext
==================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Container for HTTP request data passed to route handlers.

.. rst-class:: classref-introduction-group

Description
-----------

HTTPRequestContext encapsulates all data from an HTTP request including method, path, headers, query parameters, path parameters, and body content. It is automatically created by :ref:`HTTPServer<class_HTTPServer>` and passed to route handler callbacks.


.. tabs::

 .. code-tab:: gdscript

    HTTPServer.register_route("GET", "/api/users/{id}", func(req: HTTPRequestContext, res):
        # Access path parameter
        var user_id = req.get_path_param("id")
    
        # Access query parameter
        var format = req.get_query_param("format", "json")
    
        # Access header
        var auth = req.get_header("authorization", "")
    
        # Get client info
        print("Request from: ", req.get_client_ip())
    )
