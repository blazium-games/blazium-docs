AutorunInf
==========

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Builds an ``autorun.inf`` document for Windows disc and USB packaging.

.. rst-class:: classref-introduction-group

Description
-----------

Assembles the ``[autorun]`` section used by :ref:`EditorExportDeviceAutorun<class_EditorExportDeviceAutorun>`. USB flash drives on Windows 7 and later ignore ``OPEN=`` and ``ACTION=``; this class does not change AutoRun policy.
