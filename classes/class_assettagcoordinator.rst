AssetTagCoordinator
===================

**Inherits:** :ref:`Object<class_Object>`

Coordinates dictionary and asset-index mutations for asset tags.

.. rst-class:: classref-introduction-group

Description
-----------

**AssetTagCoordinator** wraps :ref:`AssetTagRegistry<class_AssetTagRegistry>` batch transactions for rename/remove operations and exposes undo snapshots via :ref:`undo_last_change()<class_AssetTagCoordinator_method_undo_last_change>`.
